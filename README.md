# Maina Voice

Native AI Voice Transcription & Engine Benchmarking Desktop App (Tauri v2 + Vue 3).

## Features
- 🎙️ Single-Engine Record Mode with model selection & specs guide
- ⚔️ Dual-Engine Benchmarking Mode with relative speed ratio leaderboard
- 📜 Transcript History with version tracking
- 🖥️ 100% Offline Local Whisper support + OpenRouter Cloud APIs
